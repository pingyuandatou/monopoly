# 大富翁

中国城市地名的联机大富翁。打开页面，写一个昵称，创建或加入 5 位房间号就能玩。不注册、不发邀请链接。

每个房间是一个 Cloudflare Durable Object。骰子在服务器上掷，局面写在这个对象的 SQLite 里，进程重启后还在。页面是 Worker 的静态资源。本仓库不包含部署凭据，这里不会替你执行 `wrangler deploy`。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm test
npm run dev
```

浏览器打开 [http://127.0.0.1:8791](http://127.0.0.1:8791)。

另开一个终端，用三个模拟玩家走一遍创建、加入、开始、行棋、断线和重连：

```bash
npm run sim
```

类型检查：

```bash
npm run check
```

`wrangler dev` 只在本机起服务，不会改 DNS，也不需要 Cloudflare 登录。

## 一局怎么走

1. 填写 1 到 8 位昵称。点「创建房间」会得到一个 5 位房间号，字母表去掉了容易看混的 0、O、1、I、L。也可以填已有房间号再点「加入房间」。密码可以留空。
2. 大厅显示 2 到 6 名玩家。第一个进来的人是房主，人数够了由房主点「开始」。
3. 开始之后，新的昵称只能观战。同一浏览器把令牌记在 `localStorage` 里，用原来的房间号和昵称回来，会坐回自己的位子。掉线大约 20 秒还没回来，当前这一回合会自动托管：只掷骰、不买地、不建房。

## 规则数据

棋盘和价钱都在 JSON 里，可以直接改：

- `data/board.json`：40 格。0 是起点，10 是上交所，20 是监狱，30 是深交所。没有公园、免费停车、机会、命运和税。
- `data/settings.json`：默认起步资金、起点薪水、人数和断线等待。房主开局前可以改拍卖和这些数字。保释金不在这里设。

价钱的数量级改编自 [Kris Bennett 的 lan-games](https://github.com/kbennett2000/lan-games)（MIT），原文在 `NOTICE.md`。地名和程序是中文重写。金额显示成人民币符号。

停在监狱要马上选择：

- 交保释金。金额在停下的那一刻算好并锁住：全场未抵押地产里，当前最高过路费 × 1.5，向上取整。场上还没有能收租的地，或者这个数不足 50 时，保释金是 ¥50。弹窗只显示金额和两个选项，不写出是哪块地、过路费多少。交完这一步就结束，下一回合照常走，地产也照常收租。保释金交给银行。
- 或者跳过下一回合。从现在到那一回合被跳过之前，别人停在你的地上不用交租。跳过之后恢复收租。

只用一颗骰子，点数是 1 到 6。每人每轮掷一次，掷出 6 就先处理落地，然后必须再掷；再出 6 继续，不设上限。掷出 6 若正好停在监狱，这次就停在选择保释，不再连掷。路过别人的地产不用付钱，只有棋子停下才交租。

第一次停在无主地可以买。再停到自己的地上，这一下最多升一级，四栋房是最高，没有旅馆，租金用四栋那一档封顶。不用凑齐同色，也没有均匀建房。抵押中的地不能建。租金只看这块地自己的房屋等级。买下后格子用主人颜色从棋盘内侧往外填 1/5，每建一栋再多 1/5，四栋时整格填满。铁路不能建房，买下后整格涂满。格子上不再写房价和房屋数：无主地写售价，已买的地写当前过路费（房屋按现在的栋数，铁路按主人名下的铁路条数），抵押中只写「抵押」。点开一格仍能看到房屋数和各档租金。有房子的地平时也能抵押，房子留下，抵押款只给地价的一半，抵押期间不收租，格子仍保留斜纹和「抵押」。赎回是抵押款再加一成。

交易由发起方拿出现金和自己的地，换对方的地。现金可以是 0，有房子的地也能拿去换，房子跟着走。对方可以同意、拒绝，或只改现金额再退回。发起方收到改价后只能同意或拒绝。

上交所在左下角，深交所在右上角，按当前现金抽一次行情：1/4 涨停赚 10%，1/8 疯牛赚 20%，3/8 跌停亏 10%，1/4 熊市亏 20%，四舍五入到整数。抽签用单独的服务端随机数，不跟骰子点数绑在一起。现金不大于 0 时没有变化。亏损进银行。行情按当前现金的比例计算，不会把现金扣成负数，所以不会因此进入卖地。

现金不够付租金时，弹出该玩家名下全部地块，必须选一块卖给银行，不能关闭或跳过。到手只有买入价，房子不另算钱，跟着地一起消失，地块变回无主。已抵押的地也在列表里，到手是买入价减去未还抵押款（一半），列表写明这个数。卖完仍不够就再选，直到够还；一块地都不剩就破产，债权人只拿到剩余现金。还债过程里不能卖单栋房，也不能临时抵押。平时的抵押按钮还在。断线托管时，自动卖到手最少且够补上差额的那块；没有一块够，就先卖到手最多的，再继续。同时欠好几方时，剩余现金归债权最大的一方。

另外这些地方和经典规则不一样：不买地时默认进入限时拍卖，房主可以关掉；没有免费停车奖池；房屋不设库存；接到抵押地产不用立刻补利息；房主离线大约 20 秒后，房主身份交给下一位在线玩家。最后没有破产的人获胜。目前没有电厂和水厂；如果以后加上按骰子倍数收租的地，保释金估算按 4 点。

## 部署

在已经登录 Cloudflare 的机器上：

```bash
npx wrangler deploy
```

默认会部署到 `*.workers.dev` 子域。想用自己的域名，在 `wrangler.toml` 里加一段路由（把域名换成你自己的，该域名需要已托管在 Cloudflare）：

```toml
[[routes]]
pattern = "game.example.com"
custom_domain = true
```

也可以在控制台里加：Workers 和 Pages → 这个 Worker → 设置 → 域和路由 → 添加自定义域。

第一次部署会按 `[[migrations]]` 里的 `v1` / `new_sqlite_classes = ["Room"]` 创建 SQLite 版 Durable Object。这条迁移要留着，以后只追加新的 tag，不要改掉它。

## 费用

下面按 Cloudflare 文档在 2026 年 11 月的免费额度记。数字会变，部署前看一眼 [Workers 定价](https://developers.cloudflare.com/workers/platform/pricing/) 和 [Durable Objects 定价](https://developers.cloudflare.com/durable-objects/platform/pricing/)。

- Workers 免费套餐每天 10 万次请求，每次调用 10 毫秒 CPU。静态资源不再单独计一次请求。
- Durable Objects 可以在免费套餐里用，但存储必须是 SQLite。本项目就是这样配的。
- Durable Object 请求每天 10 万次。WebSocket 收到的消息每 20 条算 1 次请求，发出去的消息和协议层 ping 不计。
- 计算时长每天 13,000 GB-s。连接用了 Hibernation API，没人说话时不计这段时长。如果改成不冬眠的 `accept()`，整段连接都会算时长，几个人挂着就容易把免费额度用完。
- SQLite 每天 500 万行读取、10 万行写入，总共 5 GB。每个房间只有一行 JSON，写入发生在每次操作之后。
- 免费额度用完后请求会失败，不会自动变成账单。计数在 UTC 零点重置。
- Workers 付费套餐最低每月 5 美元。几桌朋友局一般停在免费额度里。
- 自定义域名加在已经托管的区域上，没有另一笔域名产品费。

## 布局

- `src/game`：纯规则，不依赖 Workers，给 `vitest` 测租金、垄断、建房、监狱和破产。
- `src/room.ts`：一个房间的 WebSocket 和 SQLite。
- `src/index.ts`：`/api/health`、`/api/ws`，其余交给静态资源。
- `public/`：页面。文字都是简体中文。
